# Nazzemly — نظّملي

**Nazzemly** هو نظام تشغيل عربي لإدارة بيع وتفعيل الاشتراكات والخدمات الرقمية. يجمع في لوحة واحدة إدارة العملاء، الطلبات قيد التنفيذ، الاشتراكات، المخزون، الرصيد، التحصيل اليدوي، المصروفات، الفريق، والرسائل وبوت تيليجرام الاختياري.

> لا توجد بوابة دفع إلزامية ولا حاجة لكتابة كود. يستطيع التاجر إضافة وسائل دفعه مثل Vodafone Cash أو InstaPay، ويؤكد العميل التحويل بإيصال، ثم يعتمد التاجر الطلب من اللوحة.

## أهم المزايا

- إدارة العملاء، الملاحظات، تاريخ التواصل، والصفقات والمتابعة.
- طابور تنفيذ للطلبات الجديدة فقط؛ عند التفعيل يتحول الطلب إلى اشتراك ولا يبقى في الطابور.
- سجل اشتراكات قابل للإدارة: فتح التفاصيل، إضافة مدة، تجديد، إيقاف، استرداد، وتعويض العميل عند الحاجة.
- خدمات وباقات بفترات وأسعار وخصومات ومخزون وحسابات خاصة أو مشتركة.
- محفظة عملاء وطلبات شحن يدوية مع رقم مرجعي وصورة إيصال.
- بوت تيليجرام اختياري للشراء والشحن ومشاهدة الرصيد والاشتراكات والإبلاغ عن مشكلة.
- تذكيرات التجديد ورسائل واتساب يفتحها التاجر مباشرة من المتصفح دون API مدفوع.
- مصروفات متكررة، تقارير ربح ومصروفات، فريق وصلاحيات، استيراد وتصدير، ودعم داخلي.
- تسجيل تدقيق للعمليات الحساسة وتشفير بيانات البوت وبيانات التسليم.

## التثبيت المحلي

### 1. تنزيل المشروع وتثبيت الحزم

```bash
git clone https://github.com/y9090oussefwork/Nazzemly.git
cd Nazzemly
npm ci
```

إذا كنت لا تستخدم Git، نزّل المشروع كملف ZIP من GitHub ثم فك الضغط وشغّل `npm install` داخل مجلد المشروع.

### 2. تشغيل قاعدة PostgreSQL محلياً

إذا كان Docker Desktop مثبتاً، شغّل قاعدة بيانات جديدة:

```bash
docker run --name nazzemly-postgres -e POSTGRES_USER=nazzemly -e POSTGRES_PASSWORD=CHANGE_THIS_PASSWORD -e POSTGRES_DB=nazzemly -p 5432:5432 -d postgres:16
```

يمكنك استخدام PostgreSQL مثبتة مسبقاً بدلاً من Docker؛ المهم أن تنشئ قاعدة بيانات فارغة ومستخدماً له صلاحية عليها.

### 3. إعداد ملف البيئة

انسخ `.env.example` باسم `.env` ثم اضبط القيم التالية:

```env
DATABASE_URL="postgresql://nazzemly:CHANGE_THIS_PASSWORD@localhost:5432/nazzemly?schema=public"
APP_BASE_URL="http://localhost:3000"
APP_ENCRYPTION_KEY="ضع_قيمة_عشوائية_طولها_32_حرفاً_على_الأقل"
CRON_SECRET="ضع_قيمة_عشوائية_مختلفة"
SEED_SUPERADMIN_USERNAME="owner"
SEED_SUPERADMIN_PASSWORD="غيّرها_إلى_كلمة_مرور_قوية"
NODE_ENV="development"
```

لإنشاء قيم آمنة للمفاتيح على Windows أو macOS أو Linux:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

نفّذ الأمر مرتين: مرة لـ `APP_ENCRYPTION_KEY` ومرة لـ `CRON_SECRET`.

### 4. إنشاء الجداول وحساب مالك المنصة

```bash
npm run db:generate
npm run db:deploy
npx -y tsx prisma/seed.ts
```

أمر `seed.ts` ينشئ حساب المالك باستخدام `SEED_SUPERADMIN_USERNAME` و`SEED_SUPERADMIN_PASSWORD` فقط عند عدم وجوده. لا تضع بيانات تجريبية في بيئة الإنتاج.

### 5. تشغيل النظام

```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) ثم سجّل الدخول بحساب المالك. بعد الدخول، ابدأ بجولة الإعداد لإضافة بيانات المتجر والتواصل والدفع، وبعدها يمكنك إضافة العملاء والخدمات والاشتراكات.

## بيانات تجريبية اختيارية

لاستخدام بيانات اختبار محلية فقط:

```bash
npm run db:seed:demo
```

لا تشغّل هذا الأمر على قاعدة بيانات حقيقية للتاجر.

## ربط بوت تيليجرام

1. أنشئ بوتاً من [@BotFather](https://t.me/BotFather) واحفظ الـ Token.
2. انشر النظام على رابط HTTPS عام، ثم ضع الرابط في `APP_BASE_URL`.
3. من لوحة Nazzemly افتح **الإعدادات ← البوت والقناة** والصق الـ Token.
4. اضغط اختبار الاتصال ثم احفظ. النظام يضبط رابط البوت ويعرض حالته.

يمكن تشغيل Nazzemly بالكامل من اللوحة حتى لو لم تربط بوت تيليجرام.

## التذكيرات والمهام المجدولة

لإرسال تذكيرات التجديد أو الحملات تلقائياً، يجب استدعاء المسارات التالية بمهمة مجدولة مع ترويسة:

```text
Authorization: Bearer <CRON_SECRET>
```

- `POST /api/cron/subscription-reminders`
- `POST /api/cron/broadcasts`

## النشر في الإنتاج

1. أنشئ قاعدة PostgreSQL إنتاجية واضبط `DATABASE_URL`.
2. استخدم رابط HTTPS عام في `APP_BASE_URL` إذا ستربط بوت تيليجرام.
3. أضف مفاتيح عشوائية قوية ولا ترفع ملف `.env` إلى GitHub.
4. شغّل:

```bash
npm ci
npm run db:generate
npm run db:deploy
npm run build
npm run start
```

يوجد سكربت `deploy.sh` للخوادم التي تعمل بنظام Linux وPM2. راجع اسم عملية PM2 والمنفذ قبل تشغيله لأول مرة.

## التحقق قبل التشغيل أو النشر

```bash
npm run typecheck
npm run build
```

## بنية مختصرة

- `src/app/dashboard` واجهات التاجر والتشغيل.
- `src/app/admin` لوحة مالك المنصة.
- `src/app/actions` منطق الأعمال وإجراءات الخادم.
- `src/lib` الأمان والبوت والمحفظة والتذكيرات والتكاملات الداخلية.
- `prisma/schema.prisma` مخطط قاعدة البيانات.
- `prisma/migrations` ترقيات قاعدة البيانات المطلوبة.

## الأمان

- لا ترفع ملف `.env` أو كلمات المرور أو رموز البوت إلى GitHub.
- غيّر كلمات المرور التجريبية فوراً.
- خذ نسخة احتياطية من قاعدة الإنتاج قبل تطبيق أي Migration.
- استخدم HTTPS في الإنتاج، خصوصاً عند تفعيل بوت تيليجرام.
